# Como contribuir

1. Leia o README para configurar o ambiente e entender o escopo.
2. Abra uma issue com o problema ou melhoria, a entrada relevante e o resultado esperado.
3. Crie uma branch como `fix/descricao-curta` ou `feat/descricao-curta`.
4. Faça uma alteração focada e acrescente uma regressão quando houver um bug.
5. Execute os comandos de validação do README e abra um pull request com os resultados.

Use mensagens de commit que descrevam a mudança, como `fix: preservar ordem da fila`, `docs: explicar execução` e `test: cobrir entrada inválida`. Preserve os créditos dos exercícios e informe verificações que não conseguiu executar.
